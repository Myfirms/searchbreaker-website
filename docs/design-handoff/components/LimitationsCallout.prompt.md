# LimitationsCallout

States what a feature, score or integration cannot do.

**Use when:** Match scores, ATS scores, auto-apply support, any claim with limits.

**Do not use for:** Hiding limitations in small print; mixing with benefits.

**Content limits:** Heading is a plain question-like statement. 2–5 items; text ≤ 25 words. Same visual weight as benefit sections.

Props: see `LimitationsCallout.d.ts`. Styling comes only from tokens in `styles.css`.
