- **AlternativesHero**: Hero variant="feature" layout + AvailabilityBadge; needs no new tokens.
- **CompareTable (3+ columns)**: ComparisonTable grid supports up to 4 columns; for more, wrap in overflow-x with --grid-col-min.
- **ProsCons**: two-column FeatureGrid (data-columns="2") with StatusChip confirmed / gap.
- **VerdictBox**: Callout layout with a new data-callout value; add tokens in components.css.
- **ToolEmbed**: card tokens (--card-*) + WaitlistForm field tokens (--field-*, data-field-state) for an interactive checker shell.
- **TemplateDownload**: FeatureGrid card + Button with file icon.
