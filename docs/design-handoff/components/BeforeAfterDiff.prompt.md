# BeforeAfterDiff

Shows one proposed resume edit: requirement → evidence → edit, with provenance and review controls.

**Use when:** Resume tailoring, ATS optimizer, autofill field-source trace.

**Do not use for:** Real user data on marketing pages; edits without a cited profile fact.

**Content limits:** One edit per block; ≤ 40 words per side. Always Illustrative.

Props: see `BeforeAfterDiff.d.ts`. Styling comes only from tokens in `styles.css`.
