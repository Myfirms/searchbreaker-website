# FeatureGrid

H3 cards for sub-features.

**Use when:** Groups of 2–6 related capabilities.

**Do not use for:** Ordered processes (WorkflowSteps) or proof/stat cards.

**Content limits:** title ≤ 5 words; text ≤ 30 words; link only to published pages with a concrete label.

Props: see `FeatureGrid.d.ts`. Styling comes only from tokens in `styles.css`.
