# ArticleBody

Long-form guide content from structured blocks.

**Use when:** Guides and info pages.

**Do not use for:** Marketing sections.

**Content limits:** Paragraphs ≤ 80 words; steps 3–7; tables ≤ 4 columns, ≤ 8 rows.

Props: see `ArticleBody.d.ts`. Styling comes only from tokens in `styles.css`.
