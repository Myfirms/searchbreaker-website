# AvailabilityBadge

Shows the release state of a feature, screen, platform or workflow.

**Use when:** Next to any feature name, screenshot, workflow step or support-matrix row whose state matters.

**Do not use for:** Decoration, marketing emphasis, or as a replacement for LimitationsCallout.

**Content limits:** Labels: Live, Preview, Concept, Planned, Illustrative data. detail ≤ 4 words.

Props: see `AvailabilityBadge.d.ts`. Styling comes only from tokens in `styles.css`.
