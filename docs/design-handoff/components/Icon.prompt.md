# Icon

Inline SVG line icon from the SearchBreaker set.

**Use when:** Any icon in UI: buttons, lists, status.

**Do not use for:** Illustrations or large decorative art.

**Content limits:** Use only names from IconName. Add new icons on the 24px grid, 1.5 stroke, round caps.

Props: see `Icon.d.ts`. Styling comes only from tokens in `styles.css`.
