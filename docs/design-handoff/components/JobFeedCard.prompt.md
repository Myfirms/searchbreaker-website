# JobFeedCard

One job opening with source, date, fit reasons and missing info.

**Use when:** AI Job Finder page, in a list of 2–4.

**Do not use for:** Implying live listings on marketing pages (keep Illustrative on).

**Content limits:** matches 2–4, missing 1–3, each ≤ 10 words.

Props: see `JobFeedCard.d.ts`. Styling comes only from tokens in `styles.css`.
