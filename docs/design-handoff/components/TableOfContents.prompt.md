# TableOfContents

In-page navigation for long guides.

**Use when:** Guides with 3+ H2 sections (automatic via ArticleBody).

**Do not use for:** Short pages.

**Content limits:** Labels ≤ 6 words (use tocLabel to shorten long H2s).
