# Callout

Tip, warning or note inside article content.

**Use when:** Advice that deserves emphasis.

**Do not use for:** Limitations of the product (use LimitationsCallout).

**Content limits:** title ≤ 8 words; text ≤ 40 words; ≤ 3 per guide.

Props: see `Callout.d.ts`. Styling comes only from tokens in `styles.css`.
