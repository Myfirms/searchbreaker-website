# WaitlistDialog

Modal wrapper for WaitlistForm; target of every CTA in waitlist mode.

**Use when:** When readiness = waitlist and a CTA is activated.

**Do not use for:** When the product is live (CTA links to sign-up instead).

**Content limits:** Title ≤ 8 words, text ≤ 30 words.

Props: see `WaitlistDialog.d.ts`. Styling comes only from tokens in `styles.css`.
