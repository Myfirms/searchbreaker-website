# AnnouncementBar

Optional one-line status message above the header.

**Use when:** Pre-launch status or a real, time-bound notice.

**Do not use for:** Promotions, urgency ("only 3 spots left"), or anything decorative.

**Content limits:** text ≤ 14 words.

Props: see `AnnouncementBar.d.ts`. Styling comes only from tokens in `styles.css`.
