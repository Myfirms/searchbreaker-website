# SupportMatrix

Verified platform or source coverage with dates.

**Use when:** Autofill, auto-apply and job-source pages.

**Do not use for:** Listing platforms that were not tested.

**Content limits:** Show verified or partial rows only, each with a verified-on date. Launch with the empty state.

Props: see `SupportMatrix.d.ts`. Styling comes only from tokens in `styles.css`.
