# StickyMobileCta

Bottom action bar on mobile.

**Use when:** Long mobile pages (home, feature landings) with one main action.

**Do not use for:** Desktop; guides (use InlineCta); pages with a form already visible.

**Content limits:** text ≤ 8 words, optional.

Props: see `StickyMobileCta.d.ts`. Styling comes only from tokens in `styles.css`.
