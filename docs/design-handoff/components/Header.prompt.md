# Header

Global site header with product dropdown and mobile drawer.

**Use when:** Every page.

**Do not use for:** Inside page content.

**Content limits:** Max 7 top-level items. Product children: label ≤ 3 words, description ≤ 12 words, availability required. Pricing stays hidden until it exists.

Props: see `Header.d.ts`. Styling comes only from tokens in `styles.css`.
