# RequirementEvidencePanel

Maps job requirements to confirmed evidence with a status.

**Use when:** Job matcher, ATS pages.

**Do not use for:** Showing a numeric match score.

**Content limits:** 3–7 rows; requirement ≤ 12 words; evidence ≤ 20 words. Pair with LimitationsCallout.

Props: see `RequirementEvidencePanel.d.ts`. Styling comes only from tokens in `styles.css`.
