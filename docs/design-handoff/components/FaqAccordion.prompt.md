# FaqAccordion

Accessible FAQ with native details/summary.

**Use when:** Objection handling near the end of a page.

**Do not use for:** Content needed to understand the page (put it in the body).

**Content limits:** 4–8 questions in the user’s words; answers start with a direct answer, ≤ 60 words.

Props: see `FaqAccordion.d.ts`. Styling comes only from tokens in `styles.css`.
