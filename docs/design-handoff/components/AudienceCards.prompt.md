# AudienceCards

Who the product helps, with an honest caveat each.

**Use when:** Homepage "Who this helps".

**Do not use for:** Testimonials or personas with names and photos.

**Content limits:** 3 cards; text ≤ 25 words; caveat ≤ 12 words.

Props: see `AudienceCards.d.ts`. Styling comes only from tokens in `styles.css`.
