# ProductShot

Frame for product visuals with a visible state label.

**Use when:** Any screenshot, concept or example-data visual.

**Do not use for:** Photos of people, stock images, or unlabeled mockups.

**Content limits:** Never use a static mockup to imply live interaction. Illustrative content must contain only fictional data.

Props: see `ProductShot.d.ts`. Styling comes only from tokens in `styles.css`.
