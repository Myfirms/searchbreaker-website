# InlineCta

Contextual pointer from a guide to its one canonical product page.

**Use when:** Once per guide, after the takeaways.

**Do not use for:** Several CTAs in one guide; hard selling.

**Content limits:** title ≤ 8 words; text ≤ 25 words.

Props: see `InlineCta.d.ts`. Styling comes only from tokens in `styles.css`.
